# Join RoastCommons / 加入 RoastCommons

Requests to join the RoastCommons beta and bean library. You don't need to open an issue here by hand: the app does it when you press **Request to join** after signing in with GitHub.

加入 RoastCommons 测试版和曲线库的申请。不用手动在这里开 issue：在 app 里用 GitHub 登录后点 **申请加入**，app 会自动开。

**First, get the app / 先下载 app：** https://roastcommons.github.io/download

**Owners / 管理员:** reply `approve` (批准) or `reject` (拒绝) on a request. Approving invites the person to the organization, and their app accepts the invitation by itself. Replies from anyone who isn't an owner are ignored.
在申请下回复 `approve`（批准）或 `reject`（拒绝）。批准后会自动邀请对方加入组织，对方的 app 会自动接受。非管理员的回复会被忽略。

Requests are public: they show your GitHub name and the note you wrote. 申请是公开的，会显示你的 GitHub 名字和留言。
